### 📊 [Portfolio Tracker](https://github.com/KaanCan1/portfolio-tracker)

> Self-hosted portfolio tracking and risk-analysis dashboard, with a Claude AI layer and an MCP server.

Built end to end as a solo project — relational data model, API, market-data pipelines and AI integration. Instead of just charting prices it enforces the rules I set for myself: positions without a stop plan get flagged, new entries are blocked when the market regime is bad, and profits trigger a "pull your initial capital out" suggestion.

**What's inside**

- **Express + PostgreSQL REST API** and a relational data model for portfolio tracking and risk analysis
- **Structured-output processing layer** — Claude API `json_schema` turns unstructured financial text into schema-conformant data, with validation as a data-quality gate
- **Risk module** — Value at Risk (VaR), Monte Carlo simulation, correlation matrix and portfolio beta
- **Radar engine** — one 0–100 score per ticker from momentum, analyst consensus, fundamentals and insider activity, plus setup detection and a market-regime gate
- **Deterministic first, LLM second** — a rule engine grades every trade of the day; Claude only interprets the evidence pack it produces
- **MCP server** — lets the model query the database through tool calls, as 6 tools in Claude Code / Desktop
- **Zero-framework SPA** — no build step, 3 runtime dependencies total

### 🧺 [Open Basket](https://github.com/KaanCan1/Open-Basket) · [live demo](https://open-basket.serverpod.space/)

> One person shops, everyone adds. A live, time-boxed shared shopping basket for families and housemates, built for Serverpod's **Build Something Real** hackathon.

The shopper opens a basket for a store and a few minutes, everyone in the house adds what they need, and each item lands on every phone the moment it is added. The basket closes itself on the server when time runs out, and at the till the server works out who owes whom, down to the last kuruş.

**What's inside**

- **Closing on time, server side:** a Serverpod future call is scheduled for the deadline and freezes the basket whether or not any phone is awake; it is idempotent, and a startup sweep closes anything a restart lost
- **Live over WebSocket:** `basketStream.watch` sends a full snapshot first, then every change with the server's clock, so a phone that dropped its connection resyncs from the stream itself
- **One open basket per household, enforced by the database:** a hand-written partial unique index on top of 17 generated `.spy.yaml` models, so two people tapping *Open a basket* at once can't both succeed
- **Settlement in integer minor units:** each member owes their own items plus an even share of the receipt gap, with the remainder going to the shopper so the lines add up to exactly what was paid; a settled run is immutable
- **Location never leaves the phone:** the suggested time comes from the distance to the store, and only the remaining time is shared
- **Passwordless sign-in** with a six-digit email code, deployed on Serverpod Cloud
- **Built as a two-person team:** I own the backend and Serverpod side, Yeşim Gündüz owns Flutter and UX; every decision is recorded as a numbered ADR

### 🖥️ [Islet](https://github.com/KaanCan1/Islet)

> Turns the MacBook camera notch into something useful — what's playing, a pomodoro timer, and how much of your Claude Code limit is left.

Hover the notch and it grows into a panel; move the cursor away and it disappears completely. Lives in the menu bar with no Dock icon.

**What's inside**

- **The window never resizes** — it sits over the notch at a fixed size and the SwiftUI body animates inside it, so the spring animation never clips; while collapsed the panel passes clicks straight through to the menu bar underneath
- **Hover without a tracking area** — the cursor is read 30 times a second against two hit regions, sized to the tallest tab so switching tabs can't drop the pointer outside the panel and snap it shut
- **Now playing over AppleScript** — macOS 15.4 closed `MediaRemote` to unentitled apps, so Spotify and Apple Music are driven through their own scripting dictionaries rather than a private framework
- **Claude Code usage, from the real source** — the same endpoint `/usage` reads, for the actual utilisation and reset time; with no token reachable it falls back to reconstructing the window from local transcripts, and the panel says which of the two you are looking at
- **Content starts below the notch** — anything drawn in that strip sits behind the camera housing and is simply invisible, so the panel leaves it empty by design

### 🧾 [Sepet](https://github.com/KaanCan1/Sepet)

> Builds a personal inflation index from your own grocery receipts and puts it next to the official TÜİK series.

Official inflation measures one fixed basket meant to represent a whole country — but nobody actually buys that basket. Sepet reads your receipts and builds an index from the products you really buy.

**What's inside**

- **On-device OCR (Apple Vision)** — the receipt photo never crosses the device boundary; only matched lines reach the server, so data minimisation is an architectural property rather than a policy paragraph
- **The `eşleşme?` case** — the server resolves brand and product by fuzzy matching, but a receipt never says whether it was the 1 kg or the 3 kg; the app asks instead of guessing, showing the unit price each option would feed into the index
- **Claude as an ambiguity resolver only** — confirmed matches are cached per receipt format, so cost scales with uncertainty rather than with volume
- **Laspeyres index next to the data** — four PostgreSQL functions in a single transaction over canonical products, aliases and price observations, instead of index maths in application code
- **Official series via the TCMB EVDS API** — the machine-readable channel, since TÜİK's own portal is closed to automated access; refreshed at most once a month, with manual entry as a fallback when no key is set
- **KVKK-first** — separate disclosure and explicit-consent screens per the Board's 2026/347 decision, optional permissions off by default, guarded by a test
- **Green `main`** — PR-only flow with CI running format, `analyze --fatal-infos`, tests with coverage and Android/iOS builds; Flutter version pinned via FVM and read from the same file by CI
